# Приют: выгул собак

FastAPI + psycopg2 (без ORM) + SPA на ванильном JS (ES-модули, классы).

## Объекты

| Объект | Поля |
|---|---|
| **Будка** (`kennels`) | номер, вместимость |
| **Собака** (`dogs`) | кличка, порода, возраст, будка |
| **Помощник** (`helpers`) | имя, телефон |
| **Прогулка** (`walks`) | собака, помощник, начало, конец (пусто — идёт сейчас) |

### Состояние собаки

Считается по числу **завершённых** прогулок (идущая прогулка не засчитывается, пока не закончена):

| Прогулок | Код | Подпись | Цвет |
|---|---|---|---|
| 0 | `not_walked` | Не выгулена | красный |
| 1 | `walked_once` | Был выгул | жёлтый |
| 2+ | `walked` | Погуляла | зелёный |

Правило — в `DogStatus.from_walks` (`app/models.py`), цвета — в `static/css/style.css`.

### Правила

- Собака не может быть на двух пересекающихся по времени прогулках; помощник — тоже (409).
- Конец прогулки позже начала; ни начало, ни конец не в будущем (422).
- В будку не поместить собак больше вместимости (409).
- Собаку/помощника с прогулками удалить нельзя (409). При удалении будки собаки остаются без будки.

## Запуск

Всё в Docker — откройте http://localhost:8010:

```bash
docker compose up -d --build
```

Локально (БД в Docker на порту 5433, API на http://localhost:8000):

```bash
make db venv run
```

Строка подключения — переменная `DATABASE_URL` (см. `.env`). Схема (`app/schema.sql`)
применяется автоматически при старте. Swagger: `/docs`.

## Структура

```
app/
  db.py            Database — пул psycopg2, транзакции
  models.py        доменные классы и DogStatus
  repositories.py  SQL: BaseRepository + репозиторий на каждую таблицу
  services.py      бизнес-правила: CrudService + сервисы сущностей
  schemas.py       pydantic-схемы API
  api.py           роуты /api/*
  main.py          сборка приложения (ShelterApp)
static/
  js/api.js        ApiClient
  js/ui.js         el(), Modal, FormDialog, Toast
  js/app.js        App, Router
  js/views/*.js    View и экраны: собаки, прогулки, будки, помощники
```
